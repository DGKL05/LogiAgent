# LogiAgent 开发文档

## 当前阶段

Milestone 2 聚焦物流核心业务闭环：

```text
创建订单 -> 生成运单 -> 添加轨迹 -> 查询运单 -> 查询轨迹 -> 标记异常件
```

本阶段只实现 order、waybill、track 三个核心服务的 MVP 能力，不实现 AI Agent、路线规划、调度服务、RabbitMQ、Seata、Sentinel、Elasticsearch 和复杂权限系统。

## 开发原则

- Controller 只接收参数和返回 `Result<T>`，不直接返回 Entity。
- Entity 只在各自服务内部使用。
- DTO、Request、Feign Client 放在 `logistics-api`。
- 公共枚举、分页对象、异常和统一返回放在 `logistics-common`。
- 服务之间通过 OpenFeign 调用，不跨服务访问数据库。
- 先保证 MVP 可运行，再逐步扩展能力。

## 新增模块能力

### logistics-order-service

- 创建订单。
- 查询订单详情。
- 分页查询订单列表。
- 修改订单状态。
- 创建订单后通过 `WaybillFeignClient` 同步调用运单服务生成运单。

### logistics-waybill-service

- 根据订单号生成运单。
- 根据运单号查询运单。
- 根据订单号查询运单。
- 更新运单状态。
- 标记异常件。
- 查询异常件列表。

### logistics-track-service

- 添加物流轨迹。
- 按运单号倒序查询轨迹列表。
- 查询运单最新轨迹。

## 配置说明

三个核心业务服务均接入 MySQL 和 MyBatis Plus：

```yaml
spring:
  datasource:
    url: jdbc:mysql://${MYSQL_HOST:localhost}:${MYSQL_PORT:3306}/${MYSQL_DATABASE:logiagent}
    username: ${MYSQL_USERNAME:root}
    password: ${MYSQL_PASSWORD:${MySQLPASS:}}
```

本地环境可使用系统变量 `MySQLPASS` 保存 MySQL 密码，避免写入仓库。

## 验证命令

```bash
mvn test -pl logistics-order-service,logistics-waybill-service,logistics-track-service -am -DfailIfNoTests=false
mvn clean package -DskipTests
```

当前项目已有核心 service 单元测试，覆盖创建订单生成运单、生成运单、添加轨迹三条最小行为。
