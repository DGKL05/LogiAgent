# LogiAgent 开发文档

## 当前阶段

当前仓库处于 MVP 项目骨架阶段，目标是先保证 Spring Cloud Alibaba 多模块工程可以编译和启动。

本阶段不实现业务闭环，不接入数据库，不实现 Agent Tool Calling。

## MVP 模块

- `logistics-common`
- `logistics-api`
- `logistics-gateway`
- `logistics-auth-service`
- `logistics-order-service`
- `logistics-waybill-service`
- `logistics-track-service`
- `logistics-ai-agent-service`

## 开发原则

- 先保证可运行，再逐步补业务。
- 公共返回、错误码、业务异常放在 `logistics-common`。
- Feign Client、DTO、Request 对象放在 `logistics-api`。
- AI Agent 服务不能直接访问其他服务数据库。
- Gateway 不写具体业务逻辑。

## 当前验收标准

```bash
mvn clean package -DskipTests
```

单独启动服务前，先执行一次：

```bash
mvn install -DskipTests
```

至少启动以下两个服务：

```bash
mvn spring-boot:run -pl logistics-auth-service
mvn spring-boot:run -pl logistics-gateway
```

健康检查：

```http
GET http://localhost:9001/internal/health
GET http://localhost:8080/internal/health
```
