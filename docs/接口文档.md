## Agent 接口

### Agent 对话

```http
POST /api/agent/chat
```

请求示例：

```json
{
  "userId": 1,
  "message": "帮我分析运单 WB20260509204042075 为什么还没签收"
}
```

响应示例：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "sessionId": "AGENT20260509210000001",
    "intent": "WAYBILL_EXCEPTION_DIAGNOSIS",
    "answer": "该运单当前状态为 EXCEPTION，异常备注为：No update for a long time。最近一次轨迹为 2026-05-09 20:40:42 的「Courier collected the parcel」。系统判断可能原因是：运单已被标记为异常；异常类型为 TIMEOUT。",
    "toolCalls": [
      "WaybillTool.getWaybillByNo",
      "TrackTool.getTracksByWaybillNo",
      "TrackTool.getLatestTrackByWaybillNo"
    ]
  }
}
```

## 路线规划接口

### 规划路线

```http
POST /api/routes/plan
```

请求字段：

| 字段 | 说明 |
| --- | --- |
| `startStationId` | 起点网点 ID |
| `endStationId` | 终点网点 ID |
| `provider` | `LOCAL_DIJKSTRA` 或 `BAIDU_DRIVING`，默认 `LOCAL_DIJKSTRA` |
| `strategy` | `DISTANCE_FIRST`、`TIME_FIRST`、`COST_FIRST`、`BALANCED`、`AVOID_HIGHWAY`、`AVOID_TRAFFIC`、`HIGHWAY_FIRST`、`AVOID_FERRY` |
| `waypoints` | 可选途经网点 ID 列表，百度地图最多 10 个 |
| `coordType` | 百度坐标类型，默认 `bd09ll` |
| `retCoordType` | 百度返回坐标类型，默认 `bd09ll` |

LOCAL_DIJKSTRA 示例：

```json
{
  "startStationId": 1,
  "endStationId": 3,
  "strategy": "TIME_FIRST",
  "provider": "LOCAL_DIJKSTRA"
}
```

BAIDU_DRIVING 示例：

```json
{
  "startStationId": 1,
  "endStationId": 3,
  "strategy": "TIME_FIRST",
  "provider": "BAIDU_DRIVING",
  "coordType": "bd09ll",
  "retCoordType": "bd09ll"
}
```

响应中的 `totalDistance` 单位为公里，`totalDuration` 单位为分钟，`toll` 单位为元。百度 API 不可用时返回 `fallbackUsed=true` 和 `fallbackReason`。

## Agent 路线规划

```http
POST /api/agent/chat
```

请求示例：

```json
{
  "userId": 1,
  "message": "用百度地图规划广州到深圳真实道路路线"
}
```

Agent 会识别 `ROUTE_PLANNING` 意图：提到“百度地图”“真实道路”“实际路线”时使用 `BAIDU_DRIVING`，否则默认 `LOCAL_DIJKSTRA`；提到“最快”“最短”“成本最低”时分别映射到 `TIME_FIRST`、`DISTANCE_FIRST`、`COST_FIRST`。

## Agent 调度建议与日报

调度建议：

```json
{
  "userId": 1,
  "message": "今天哪个网点压力最大"
}
```

物流日报：

```json
{
  "userId": 1,
  "message": "生成今天的物流日报"
}
```

日报返回 Markdown，包含日期、订单统计、异常件数量、网点负载排行、Agent 分析结论和调度建议。当前 MVP 对新增运单数、已签收数量、轨迹更新数量暂未提供独立统计接口，返回中会明确说明。
