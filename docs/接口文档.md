## 路线规划接口

### 规划路线

```http
POST /api/routes/plan
```

请求字段：

| 字段 | 说明 |
| --- | --- |
| `startStationId` | 起点网点 ID |
| `endStationId` | 终点网点 ID |
| `provider` | `LOCAL_DIJKSTRA` 或 `BAIDU_DRIVING`，默认 `LOCAL_DIJKSTRA` |
| `strategy` | `DISTANCE_FIRST`、`TIME_FIRST`、`COST_FIRST`、`BALANCED`、`AVOID_HIGHWAY`、`AVOID_TRAFFIC`、`HIGHWAY_FIRST`、`AVOID_FERRY` |
| `waypoints` | 可选途经网点 ID 列表，百度地图最多 10 个 |
| `coordType` | 百度坐标类型，默认 `bd09ll` |
| `retCoordType` | 百度返回坐标类型，默认 `bd09ll` |

LOCAL_DIJKSTRA 示例：

```json
{
  "startStationId": 1,
  "endStationId": 3,
  "strategy": "TIME_FIRST",
  "provider": "LOCAL_DIJKSTRA"
}
```

BAIDU_DRIVING 示例：

```json
{
  "startStationId": 1,
  "endStationId": 3,
  "strategy": "TIME_FIRST",
  "provider": "BAIDU_DRIVING",
  "coordType": "bd09ll",
  "retCoordType": "bd09ll"
}
```

响应中的 `totalDistance` 单位为公里，`totalDuration` 单位为分钟，`toll` 单位为元。百度 API 不可用时返回 `fallbackUsed=true` 和 `fallbackReason`。

## Agent 路线规划

```http
POST /api/agent/chat
```

请求示例：

```json
{
  "userId": 1,
  "message": "用百度地图规划广州到深圳真实道路路线"
}
```

Agent 会识别 `ROUTE_PLANNING` 意图：提到“百度地图”“真实道路”“实际路线”时使用 `BAIDU_DRIVING`，否则默认 `LOCAL_DIJKSTRA`；提到“最快”“最短”“成本最低”时分别映射到 `TIME_FIRST`、`DISTANCE_FIRST`、`COST_FIRST`。

## Agent 调度建议与日报

调度建议：

```json
{
  "userId": 1,
  "message": "今天哪个网点压力最大"
}
```

物流日报：

```json
{
  "userId": 1,
  "message": "生成今天的物流日报"
}
```

日报返回 Markdown，包含日期、订单统计、异常件数量、网点负载排行、Agent 分析结论和调度建议。当前 MVP 对新增运单数、已签收数量、轨迹更新数量暂未提供独立统计接口，返回中会明确说明。
## 统计接口

### 订单日统计

```http
GET /api/orders/statistics/daily?date=2026-05-10
```

返回字段：

- `totalOrderCount`：历史总订单数。
- `newOrderCount`：指定日期新增订单数。
- `cancelledOrderCount`：指定日期取消订单数。
- `orderStatusCountMap`：当前订单状态分布。

### 订单范围统计

```http
GET /api/orders/statistics/range?startDate=2026-05-01&endDate=2026-05-10
```

### 运单日统计

```http
GET /api/waybills/statistics/daily?date=2026-05-10
```

返回字段：

- `totalWaybillCount`：历史总运单数。
- `newWaybillCount`：指定日期新增运单数。
- `signedWaybillCount`：指定日期签收运单数，MVP 口径为当前状态为 `SIGNED` 且 `update_time` 在统计日期内。
- `exceptionWaybillCount`：当前异常运单数，MVP 口径为当前状态为 `EXCEPTION`。
- `transportingWaybillCount`：当前运输中运单数。
- `waybillStatusCountMap`：当前运单状态分布。
- `exceptionTypeCountMap`：当前异常类型分布，排除 null/空值后按枚举类型统计。

### 运单范围统计

```http
GET /api/waybills/statistics/range?startDate=2026-05-01&endDate=2026-05-10
```

### 轨迹日统计

```http
GET /api/tracks/statistics/daily?date=2026-05-10
```

返回字段：

- `trackUpdateCount`：指定日期轨迹更新数量。
- `activeWaybillCount`：指定日期有轨迹更新的运单数量。
- `actionCountMap`：轨迹动作分布。
- `latestTrackUpdateTime`：最新轨迹更新时间。

### 单运单轨迹统计

```http
GET /api/tracks/statistics/waybill/{waybillNo}
```

## Agent 真实统计日报

```http
POST /api/agent/chat
```

```json
{
  "userId": 1,
  "message": "生成今天的物流日报"
}
```

`LogisticsReportAgent` 会通过 `ReportDataTool` 调用订单、运单、轨迹统计接口，并结合调度服务返回 Markdown 日报。某项统计失败时，对应字段显示“该项数据暂不可用”。
## Milestone 6 管理员后台接口

后台接口统一通过 Gateway 访问 `/api/admin/**`，当前阶段只提供接口能力，不实现完整 RBAC。

- 订单管理：`GET /api/admin/orders`、`GET /api/admin/orders/{orderNo}`、`PUT /api/admin/orders/{orderNo}/status`、`GET /api/admin/orders/statistics`
- 运单管理：`GET /api/admin/waybills`、`GET /api/admin/waybills/{waybillNo}`、`PUT /api/admin/waybills/{waybillNo}/status`、`POST /api/admin/waybills/{waybillNo}/exception`、`PUT /api/admin/waybills/{waybillNo}/exception/resolve`
- 异常件管理：`GET /api/admin/exceptions`、`GET /api/admin/exceptions/{waybillNo}`、`PUT /api/admin/exceptions/{waybillNo}/resolve`、`GET /api/admin/exceptions/statistics`
- 网点管理：`GET /api/admin/stations`、`GET /api/admin/stations/{stationId}`、`POST /api/admin/stations`、`PUT /api/admin/stations/{stationId}`、`DELETE /api/admin/stations/{stationId}`
- 线路管理：`GET /api/admin/routes`、`GET /api/admin/routes/{routeId}`、`POST /api/admin/routes`、`PUT /api/admin/routes/{routeId}`、`DELETE /api/admin/routes/{routeId}`
- 调度任务：`GET /api/admin/dispatch/tasks`、`GET /api/admin/dispatch/tasks/{taskNo}`、`POST /api/admin/dispatch/tasks`、`PUT /api/admin/dispatch/tasks/{taskNo}/status`
- Agent 会话：`GET /api/admin/agent/sessions`、`GET /api/admin/agent/sessions/{sessionId}`、`GET /api/admin/agent/sessions/{sessionId}/tool-logs`、`GET /api/admin/agent/statistics`
- 数据看板：`GET /api/admin/dashboard/overview`、`GET /api/admin/dashboard/trends`、`GET /api/admin/dashboard/risks`

Dashboard 由 ai-agent-service 通过 Feign 聚合业务服务数据。某个服务不可用时返回部分数据，并在 `unavailableFields` 中标记不可用字段。
