# LogiAgent 接口文档

统一响应格式：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

## 健康检查

```http
GET /internal/health
```

## Agent 接口

### Agent 对话

```http
POST /api/agent/chat
```

请求示例：

```json
{
  "userId": 1,
  "message": "帮我分析运单 WB20260509204042075 为什么还没签收"
}
```

响应示例：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "sessionId": "AGENT20260509210000001",
    "intent": "WAYBILL_EXCEPTION_DIAGNOSIS",
    "answer": "该运单当前状态为 EXCEPTION，异常备注为：No update for a long time。最近一次轨迹为 2026-05-09 20:40:42 的「Courier collected the parcel」。系统判断可能原因是：运单已被标记为异常；异常类型为 TIMEOUT。",
    "toolCalls": [
      "WaybillTool.getWaybillByNo",
      "TrackTool.getTracksByWaybillNo",
      "TrackTool.getLatestTrackByWaybillNo"
    ]
  }
}
```

### 查询 Agent 会话

```http
GET /api/agent/sessions/{sessionId}
```

### 分页查询 Agent 会话

```http
GET /api/agent/sessions?page=1&size=10
```

## 订单接口

### 创建订单

```http
POST /api/orders
```

### 查询订单详情

```http
GET /api/orders/{orderNo}
```

### 查询订单列表

```http
GET /api/orders?page=1&size=10
```

### 修改订单状态

```http
PUT /api/orders/{orderNo}/status
```

## 运单接口

### 生成运单

```http
POST /api/waybills
```

### 查询运单详情

```http
GET /api/waybills/{waybillNo}
```

### 根据订单号查询运单

```http
GET /api/waybills/order/{orderNo}
```

### 更新运单状态

```http
PUT /api/waybills/{waybillNo}/status
```

### 标记异常件

```http
POST /api/waybills/{waybillNo}/exception
```

### 查询异常件列表

```http
GET /api/waybills/exceptions?page=1&size=10
```

## 轨迹接口

### 添加物流轨迹

```http
POST /api/tracks
```

### 查询运单轨迹列表

```http
GET /api/tracks/waybill/{waybillNo}
```

### 查询最新轨迹

```http
GET /api/tracks/waybill/{waybillNo}/latest
```
