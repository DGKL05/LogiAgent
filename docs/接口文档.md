# LogiAgent 接口文档

统一响应格式：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

## 健康检查

```http
GET /internal/health
```

## 订单接口

### 创建订单

```http
POST /api/orders
```

请求示例：

```json
{
  "senderId": 1,
  "receiverName": "Zhang San",
  "receiverPhone": "13800000000",
  "receiverAddress": "Shenzhen Nanshan",
  "goodsName": "electronics",
  "weight": 2.50
}
```

响应 `data`：

```json
{
  "orderNo": "OD20260509203000001",
  "waybillNo": "WB20260509203000002"
}
```

### 查询订单详情

```http
GET /api/orders/{orderNo}
```

### 查询订单列表

```http
GET /api/orders?page=1&size=10
```

### 修改订单状态

```http
PUT /api/orders/{orderNo}/status
```

```json
{
  "status": "CANCELLED"
}
```

可用状态：`CREATED`、`WAYBILL_CREATED`、`CANCELLED`。

## 运单接口

### 生成运单

```http
POST /api/waybills
```

```json
{
  "orderNo": "OD20260509203000001"
}
```

### 查询运单详情

```http
GET /api/waybills/{waybillNo}
```

### 根据订单号查询运单

```http
GET /api/waybills/order/{orderNo}
```

### 更新运单状态

```http
PUT /api/waybills/{waybillNo}/status
```

```json
{
  "status": "TRANSPORTING"
}
```

可用状态：`CREATED`、`WAITING_COLLECT`、`COLLECTED`、`TRANSPORTING`、`ARRIVED_STATION`、`DELIVERING`、`SIGNED`、`CANCELLED`、`EXCEPTION`。

### 标记异常件

```http
POST /api/waybills/{waybillNo}/exception
```

```json
{
  "exceptionType": "TIMEOUT",
  "exceptionReason": "No update for a long time"
}
```

异常类型：`TIMEOUT`、`DAMAGED`、`LOST`、`REJECTED`、`ADDRESS_ERROR`、`OTHER`。

### 查询异常件列表

```http
GET /api/waybills/exceptions?page=1&size=10
```

## 轨迹接口

### 添加物流轨迹

```http
POST /api/tracks
```

```json
{
  "waybillNo": "WB20260509203000002",
  "action": "COLLECTED",
  "description": "Courier collected the parcel",
  "operatorId": 10
}
```

可用动作：`CREATED`、`WAITING_COLLECT`、`COLLECTED`、`TRANSPORTING`、`ARRIVED_STATION`、`DELIVERING`、`SIGNED`、`EXCEPTION`。

### 查询运单轨迹列表

```http
GET /api/tracks/waybill/{waybillNo}
```

轨迹按 `eventTime` 倒序返回。

### 查询最新轨迹

```http
GET /api/tracks/waybill/{waybillNo}/latest
```
