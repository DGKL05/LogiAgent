# LogiAgent 接口文档

## 当前接口范围

当前只提供服务健康检查接口，业务接口将在后续阶段补充。

## 健康检查

### 请求

```http
GET /internal/health
```

### 响应示例

```json
{
  "code": 200,
  "message": "success",
  "data": "logistics-auth-service"
}
```

## Gateway 路由占位

| 路径 | 目标服务 |
| --- | --- |
| `/api/auth/**` | `logistics-auth-service` |
| `/api/orders/**` | `logistics-order-service` |
| `/api/waybills/**` | `logistics-waybill-service` |
| `/api/tracks/**` | `logistics-track-service` |
| `/api/agent/**` | `logistics-ai-agent-service` |
