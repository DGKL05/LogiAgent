# LogiAgent 数据库设计

## 初始化脚本

本阶段初始化脚本：

```text
docs/sql/init-logistics-core.sql
```

执行示例：

```bash
mysql -h 127.0.0.1 -P 3306 -u root -p%MySQLPASS% < docs/sql/init-logistics-core.sql
```

PowerShell：

```powershell
$env:MYSQL_PWD=$env:MySQLPASS
Get-Content -Raw docs/sql/init-logistics-core.sql | mysql -h 127.0.0.1 -P 3306 -u root
```

## 命名约定

- 表名使用 `t_xxx`。
- 主键统一使用 `id BIGINT`。
- 订单号 `order_no` 唯一。
- 运单号 `waybill_no` 唯一。
- 时间字段使用 `create_time`、`update_time`。
- 逻辑删除字段后续按需加入，本阶段不引入。

## t_order

订单表，归属 `logistics-order-service`。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | BIGINT | 主键 |
| order_no | VARCHAR(32) | 订单号，唯一 |
| sender_id | BIGINT | 寄件人 ID |
| receiver_name | VARCHAR(64) | 收件人姓名 |
| receiver_phone | VARCHAR(32) | 收件人手机号 |
| receiver_address | VARCHAR(255) | 收件地址 |
| goods_name | VARCHAR(128) | 物品名称 |
| weight | DECIMAL(10,2) | 重量 |
| status | VARCHAR(32) | 订单状态 |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |

## t_waybill

运单表，归属 `logistics-waybill-service`。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | BIGINT | 主键 |
| waybill_no | VARCHAR(32) | 运单号，唯一 |
| order_no | VARCHAR(32) | 订单号，唯一 |
| current_status | VARCHAR(32) | 当前运单状态 |
| exception_type | VARCHAR(32) | 异常类型 |
| exception_reason | VARCHAR(255) | 异常原因 |
| create_time | DATETIME | 创建时间 |
| update_time | DATETIME | 更新时间 |

## t_track

轨迹表，归属 `logistics-track-service`。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | BIGINT | 主键 |
| waybill_no | VARCHAR(32) | 运单号 |
| action | VARCHAR(32) | 轨迹动作 |
| description | VARCHAR(255) | 轨迹描述 |
| operator_id | BIGINT | 操作人 ID |
| event_time | DATETIME | 事件发生时间 |
| create_time | DATETIME | 创建时间 |

索引：

- `idx_track_waybill_time (waybill_no, event_time)` 用于按运单号倒序查询轨迹。
