# LogiAgent 数据库设计

## 当前阶段

MVP 项目骨架阶段暂不创建数据库表，也不引入 MyBatis Plus、MySQL、Redis。

后续业务阶段再补充数据库表结构。

## 规划核心表

- `t_user`
- `t_order`
- `t_waybill`
- `t_track`
- `t_station`
- `t_route`
- `t_dispatch_task`
- `t_agent_session`
- `t_agent_tool_log`

## 命名约定

- 表名使用 `t_xxx`
- 主键统一使用 `id BIGINT`
- 创建时间使用 `create_time`
- 更新时间使用 `update_time`
- 逻辑删除字段 `deleted` 后续按需加入
