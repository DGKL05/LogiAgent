# LogiAgent 部署文档

## 本地依赖

- JDK 17+
- Maven 3.8+
- Docker / Docker Compose
- MySQL 8
- Nacos

## 启动基础组件

```bash
docker compose up -d mysql nacos
```

Nacos 控制台：

```text
http://localhost:8848/nacos
```

## 初始化数据库

```powershell
$env:MYSQL_PWD=$env:MySQLPASS
Get-Content -Raw docs/sql/init-logistics-core.sql | mysql -h 127.0.0.1 -P 3306 -u root
```

脚本包含核心业务表和 Agent 表。

## 编译

```bash
mvn clean package -DskipTests
```

## 启动服务

建议分别开多个终端：

```bash
mvn spring-boot:run -pl logistics-waybill-service
mvn spring-boot:run -pl logistics-track-service
mvn spring-boot:run -pl logistics-ai-agent-service
mvn spring-boot:run -pl logistics-gateway
```

如需创建新的运单数据，也启动：

```bash
mvn spring-boot:run -pl logistics-order-service
```

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `NACOS_SERVER_ADDR` | `127.0.0.1:8848` | Nacos 服务地址 |
| `MYSQL_HOST` | `localhost` | MySQL 地址 |
| `MYSQL_PORT` | `3306` | MySQL 端口 |
| `MYSQL_DATABASE` | `logiagent` | MySQL 数据库 |
| `MYSQL_USERNAME` | `root` | MySQL 用户名 |
| `MYSQL_PASSWORD` | `${MySQLPASS}` | MySQL 密码 |
| `OPENAI_API_KEY` | 空 | 后续接入大模型使用，本阶段不强制 |

## Agent 验证

```bash
curl -X POST http://localhost:8080/api/agent/chat ^
  -H "Content-Type: application/json" ^
  -d "{\"userId\":1,\"message\":\"帮我分析运单 WB20260509204042075 为什么还没签收\"}"
```

数据库验证：

```sql
SELECT session_id, intent, question FROM t_agent_session ORDER BY create_time DESC LIMIT 5;
SELECT session_id, tool_name, success, cost_ms FROM t_agent_tool_log ORDER BY create_time DESC LIMIT 10;
```
## 路线服务与百度地图配置

启动 route-service：

```bash
mvn spring-boot:run -pl logistics-route-service
```

Gateway 路由：

```text
/api/routes/** -> lb://logistics-route-service
```

默认不启用百度地图：

```yaml
baidu:
  map:
    enabled: false
    ak: ${BAIDU_MAP_AK:}
```

如需验证百度地图轻量级路线规划 API：

1. 在百度地图开放平台申请 Web 服务 AK。
2. 设置环境变量 `BAIDU_MAP_AK`，不要写入代码，不要提交 `.env`。
3. 将 `baidu.map.enabled` 配置为 `true`。
4. 请求 `POST /api/routes/plan`，`provider` 使用 `BAIDU_DRIVING`。

未配置 AK 时，只验证 fallback 到 `LOCAL_DIJKSTRA` 的链路。百度 API 坐标格式为 `纬度,经度`。

## 调度服务与日报验证

启动调度服务：

```bash
mvn spring-boot:run -pl logistics-dispatch-service
```

如果需要验证 Agent 日报，至少启动：

```bash
mvn spring-boot:run -pl logistics-gateway
mvn spring-boot:run -pl logistics-order-service
mvn spring-boot:run -pl logistics-waybill-service
mvn spring-boot:run -pl logistics-dispatch-service
mvn spring-boot:run -pl logistics-ai-agent-service
```

调度验证：

```bash
curl http://localhost:8080/api/dispatch/stations/load-ranking
curl http://localhost:8080/api/dispatch/suggestions
```

Agent 调度建议：

```bash
curl -X POST http://localhost:8080/api/agent/chat ^
  -H "Content-Type: application/json" ^
  -d "{\"userId\":1,\"message\":\"今天哪个网点压力最大\"}"
```

Agent 物流日报：

```bash
curl -X POST http://localhost:8080/api/agent/chat ^
  -H "Content-Type: application/json" ^
  -d "{\"userId\":1,\"message\":\"生成今天的物流日报\"}"
```
