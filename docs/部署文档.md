# LogiAgent 部署文档

## 本地依赖

- JDK 17+
- Maven 3.8+
- Docker / Docker Compose

## 启动基础组件

```bash
docker compose up -d mysql nacos
```

Nacos 控制台：

```text
http://localhost:8848/nacos
```

MySQL：

```text
127.0.0.1:3306
database: logiagent
username: root
password: 读取系统环境变量 MySQLPASS
```

## 初始化数据库

```bash
mysql -h 127.0.0.1 -P 3306 -u root -p%MySQLPASS% < docs/sql/init-logistics-core.sql
```

PowerShell 可以使用：

```powershell
$env:MYSQL_PWD=$env:MySQLPASS
Get-Content -Raw docs/sql/init-logistics-core.sql | mysql -h 127.0.0.1 -P 3306 -u root
```

也可以进入 MySQL 客户端后执行：

```sql
source docs/sql/init-logistics-core.sql;
```

## 编译

```bash
mvn clean package -DskipTests
```

## 启动业务服务

建议分别开多个终端：

```bash
mvn spring-boot:run -pl logistics-waybill-service
mvn spring-boot:run -pl logistics-order-service
mvn spring-boot:run -pl logistics-track-service
mvn spring-boot:run -pl logistics-gateway
```

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `NACOS_SERVER_ADDR` | `127.0.0.1:8848` | Nacos 服务地址 |
| `MYSQL_HOST` | `localhost` | MySQL 地址 |
| `MYSQL_PORT` | `3306` | MySQL 端口 |
| `MYSQL_DATABASE` | `logiagent` | MySQL 数据库 |
| `MYSQL_USERNAME` | `root` | MySQL 用户名 |
| `MYSQL_PASSWORD` | `${MySQLPASS}` | MySQL 密码 |
| `MySQLPASS` | 空 | 本地系统变量，用于保存数据库密码 |

## 验证链路

1. 创建订单：`POST http://localhost:8080/api/orders`
2. 查询订单：`GET http://localhost:8080/api/orders/{orderNo}`
3. 查询运单：`GET http://localhost:8080/api/waybills/order/{orderNo}`
4. 添加轨迹：`POST http://localhost:8080/api/tracks`
5. 查询轨迹：`GET http://localhost:8080/api/tracks/waybill/{waybillNo}`
6. 标记异常件：`POST http://localhost:8080/api/waybills/{waybillNo}/exception`
